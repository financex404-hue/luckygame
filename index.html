खेल के नियम (Game Rules)

  1. दोनों खिलाड़ी बारी-बारी से पासा फेंकते हैं
  2. जो खिलाड़ी बड़ा नंबर निकालता है, वह जीतता है
  3. अगर दोनों को समान नंबर आता है, तो ड्रॉ होता है
  4. आप कितनी बार खेलना चाहें, उतनी बार खेल सकते हैं
  5. Reset बटन से खेल दोबारा शुरू करो

How to Play:

  1. Both players take turns rolling the dice
  2. The player with the higher number wins
  3. If both get the same number, it's a draw
  4. You can play as many times as you want
  5. Click Reset to start a new game
