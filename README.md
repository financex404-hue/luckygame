## 📋 How to Play

1. **खेल शुरू करो (Start the Game)**
   - Player 1 को "Roll Dice" बटन पर क्लिक करना है
   - Click on "Roll Dice" button for Player 1

2. **Player 2 की बारी (Player 2's Turn)**
   - अब Player 2 को "Roll Dice" बटन पर क्लिक करना है
   - Now click on "Roll Dice" button for Player 2

3. **परिणाम देखो (Check Result)**
   - जो खिलाड़ी बड़ा नंबर निकालता है, वह जीतता है
   - The player with higher number wins!

4. **दोबारा खेलो (Play Again)**
   - दोनों खिलाड़ी फिर से अपना-अपना पासा फेंक सकते हैं
   - Both players can roll dice again

5. **Reset करो (Reset Game)**
   - "Reset Game" बटन से खेल शुरू से शुरू करो
   - Click "Reset Game" to start fresh

---

## 🎯 Game Rules

**नियम (Rules):**
1. दोनों खिलाड़ी बारी-बारी से पासा फेंकते हैं
   - Both players take turns rolling the dice
   
2. जो खिलाड़ी बड़ा नंबर निकालता है, वह जीतता है
   - The player with the higher number wins
   
3. अगर दोनों को समान नंबर आता है, तो ड्रॉ होता है
   - If both get the same number, it's a draw
   
4. आप कितनी बार खेलना चाहें, उतनी बार खेल सकते हैं
   - You can play as many times as you want
   
5. Reset बटन से खेल दोबारा शुरू करो
   - Click Reset to start a new game

## 🔧 Customization

### Change Colors
Edit `style.css` and modify the gradient colors:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Change Dice Range
Edit `script.js`:
```javascript
// Change from 6-sided to 20-sided dice
return Math.floor(Math.random() * 20) + 1;
```
